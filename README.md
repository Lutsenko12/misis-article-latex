Гибридный метод классификации научно-технических текстов на основе RuBERT и графов знаний

Статья для сборника НИТУ «МИСиС» по результатам НИР (VI семестр, 2025–2026 уч. год). Автор: Луценко А.В., группа БПМ-23-ПО-1, кафедра инженерной кибернетики, направление 01.03.04 «Прикладная математика». Научный руководитель: профессор, д.э.н. Мишуров С.С.

Оформление: LaTeX-шаблон sadekovlar/misis-article-latex (misisarticle.cls, LPPL 1.3c, без изменений).

О работе

Предложен метод классификации русскоязычных научно-технических текстов, в котором контекстный вектор документа (RuBERT, токен [CLS]) объединяется конкатенацией с графовым вектором, полученным усреднением заранее обученных эмбеддингов узлов графа знаний (TransE, RotatE или node2vec). Метод не изменяет механизм самовнимания трансформера и не использует графовые нейронные сети при инференсе: извлечение графовых признаков сводится к поиску в таблице эмбеддингов.

Схема метода:

Текстовый поток: RuBERT, вектор V_text размерности 768.
Графовый поток: NER, entity linking, mean pooling эмбеддингов узлов, вектор V_graph.
Слияние: V_final = [V_text ⊕ V_graph], затем MLP (ReLU, Dropout, Softmax).

Метрики: Macro F1 (основная), Micro F1, Accuracy, время инференса. Базовые модели: TF-IDF + LR/SVM, RuBERT (text-only), опционально K-BERT / ERNIE.
