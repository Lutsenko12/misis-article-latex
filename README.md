# Двухпоточный гибридный метод классификации научно-технических текстов на основе предобученной языковой модели и эмбеддингов графа знаний

Оформление: LaTeX-шаблон [sadekovlar/misis-article-latex](https://github.com/sadekovlar/misis-article-latex) (`misisarticle.cls`, LPPL 1.3c, без изменений).

## О работе

Предложен метод классификации русскоязычных научно-технических текстов, в котором контекстный вектор документа (RuBERT, токен [CLS]) объединяется конкатенацией с графовым вектором, полученным усреднением заранее обученных эмбеддингов узлов графа знаний (TransE, RotatE или node2vec). Метод не изменяет механизм самовнимания трансформера и не использует графовые нейронные сети при инференсе: извлечение графовых признаков сводится к поиску в таблице эмбеддингов.

Схема метода :

1. Текстовый поток: RuBERT, вектор `V_text` размерности 768.
2. Графовый поток: NER, entity linking, mean pooling эмбеддингов узлов, вектор `V_graph`.
3. Слияние: `V_final = [V_text ⊕ V_graph]`, затем MLP (ReLU, Dropout, Softmax).

Метрики: Macro F1 (основная), Micro F1, Accuracy, время инференса. Базовые модели: TF-IDF + LR/SVM, RuBERT (text-only), опционально K-BERT / ERNIE.

## Сборка статьи

Компилятор: XeLaTeX или tectonic.

```
make article        # PDF: build/article.pdf
make dist           # архив для Overleaf
```

В Overleaf: New Project → Upload Project → Settings → Compiler → XeLaTeX; главный файл `article.tex`.
